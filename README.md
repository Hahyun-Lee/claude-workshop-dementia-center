# 클로드로 센터 업무 가볍게 — 치매안심센터 직원 특강 자료

2026-11-09 동작구 치매안심센터 직원 특강(강사 이하현, 보라매병원 정신건강의학과)에서 쓴 자료입니다. 특강이 끝난 뒤에도 이 주소에서 받을 수 있습니다.

## 받을 것

| 폴더 | 내용 |
|---|---|
| `skill/` | **치매안심센터 문서 작성 스킬** — `dementia-center-documents.zip`을 claude.ai에 올리면 안내문·계획서·평가서·결과보고서 규칙이 계정에 붙습니다. 규칙 본문은 `SKILL.md` |
| `handouts/` | 유인물 1(규칙 템플릿·프롬프트 카드·안전 규칙), 유인물 2(무료/유료 기능·Claude in Chrome·컴퓨터 사용·GitHub 가입) |
| `sample/` | 실습용 **가명 실적표** 엑셀 — 모두 가짜 숫자, 사람 정보 없음 |
| `slides/` | 특강 슬라이드 8장(pdf·pptx)과 실습 2 예시 차트 |

## 스킬 설치 (3분)

1. claude.ai → Settings → Capabilities → 「Code execution and file creation」 켜기
2. Customize → Skills → + → Upload a skill → `dementia-center-documents.zip`
3. 확인: 「11월 가족교실 안내문 써 줘」 → 제목·대상·일시·장소·신청·문의 순서로 나오면 성공

zip 업로드가 안 되면 `SKILL.md` 내용을 대화창에 붙여 넣고 「이 규칙을 스킬로 저장해 줘」라고 해도 됩니다.

## 안전 규칙 4개

1. 대상자 실명·연락처·진단 정보는 입력하지 않습니다. 「대상자 A, 70대 여성」으로 바꿉니다.
2. 사례관리 기록·검진 결과 **원본 파일은 올리지 않습니다.** 빈 서식이나 가짜 데이터만.
3. Settings → Privacy에서 대화를 모델 학습에 쓰는 옵션을 끕니다.
4. 치매 의학 정보·규정은 반드시 원문(보건복지부 치매안심센터 운영 가이드)으로 확인합니다.

근거: 개인정보보호위원회 「생성형 AI 개발·활용을 위한 개인정보 처리 안내서」(2025-08).
